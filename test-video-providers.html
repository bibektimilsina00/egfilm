📋 How This Test Works

  • API Mode: This page fetches providers from your actual Next.js API endpoint
  • Same Data: Uses the exact same database records as your production app
  • No CSP: This HTML file has NO Content Security Policy, so all iframes should load
  • Comparison: If providers work here but not in your Next.js app, the issue is with headers/CSP

🔧 Troubleshooting

  • Make sure your Next.js dev server is running on the correct port
  • Check browser console for CORS errors when fetching from API
  • If a provider works here but not in Next.js, check your CSP headers
